# user_registration_and_login
A simple PHP and MySQL project for user registration and login. Features include secure password md5, session management, and Bootstrap-based UI for responsiveness.

// readme

This is a simple User Registration and Login project built using PHP, MySQL, and Bootstrap. The system allows users to register, log in, and log out securely. It includes session handling and basic form validation.

🔐 Features
User registration with input validation

User login with session management

Password md5 for security

Logout functionality

Bootstrap UI for responsiveness

🛠️ Technologies Used
PHP (Core PHP)

MySQL

Bootstrap
